## What changed

### 1. Brand asset package (new)

Generated by `scripts/build_brand_assets.py` (Pillow):

- `/favicon.svg` — vector "iL" monogram on navy gradient
- `/favicon.ico` — multi-size 16/32/48
- `/favicon-16x16.png`, `/favicon-32x32.png`
- `/apple-touch-icon.png` (180×180)
- `/icon-192.png`, `/icon-512.png`, `/icon-maskable-512.png`
- `/site.webmanifest` (name, short_name, theme color, icons)
- `/og-default.png` (1200×630), `/og-default.jpg` fallback
- `/social-assets/og-default.png` (mirrored for legacy reference)

The mark is a neutral information-resource brand — no gavel, no scales, no
courthouse. Designed for legibility at 16×16. Background uses the existing
`#01366c` navy / `#fbba00` yellow palette.

### 2. Centralized SEO metadata system

- `seo/config.py` — site URL, brand suffix, default copy, length limits, ES
  terminology map, page-classification rules.
- `scripts/seo_audit.py` — comprehensive HTML head audit producing CSV +
  Markdown reports.
- `scripts/seo_normalize_head.py` — idempotent head rewrite that:
  - injects all favicon, apple-touch-icon, manifest and theme-color links
  - inserts a marker-bracketed `<!-- SEO_BLOCK_START --> ... <!-- SEO_BLOCK_END -->`
    section with full Open Graph + Twitter Card metadata derived from the
    page's title/description/canonical
  - normalizes `<html lang>` to `en-US` / `es-US`
  - tightens overlong titles (>62 chars) using brand-aware abbreviations
  - tightens overlong descriptions (>165 chars) at sentence/word boundary
  - repairs known mojibake (windows-1252-as-utf-8 sequences and U+FFFD)
  - adds `noindex, follow` to redirect-source URLs and `/thank-you`
- `scripts/seo_validate_hreflang.py` — checks reciprocity, no-redirect-target,
  Spanish-canonical sanity.
- `scripts/seo_validate_schema.py` — disallows law-firm types on neutral
  pages, validates Article fields, ensures FAQ Q&A is visible.
- `scripts/seo_render_faq.py` — for pages whose FAQ schema Q&A wasn't visible,
  renders a `<section class="seo-faq"> <details>` block from the *existing*
  schema content (no fabrication).
